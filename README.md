
# Hope for All Foundation Website Project

## Project Overview
This web application is built for the **Hope for All Foundation**, a non-profit organisation based in Polokwane, South Africa. The primary objective is to enhance online donation efficiency, streamline volunteer applications, and highlight community social upliftment programs.

## Website Features
- **Semantic HTML5 Layout:** Clean structure utilizing modern HTML tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Interactive Forms:** Multi-field volunteer and enquiry submission interface.
- **Location Integration:** Embedded Google Maps frame pointing to Polokwane operations.
- **Cross-Page Navigation:** Consistent header navigation across all five core pages.

## Page File Structure
- `index.html`: Home page featuring hero section, mission overview, and impact statistics.
- `aboutus.html`: Organizational history, mission/vision statements, and staff profiles.
- `services.html`: Breakdown of community feeding, shelter care, and skills programs.
- `enquiry.html`: Online volunteer application and inquiry forms.
- `contact.html`: Office address, operating hours, direct contact details, and location map.

## Technologies Used
- HTML5
- CSS3
- Git & GitHub for Version Control
